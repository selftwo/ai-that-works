# The Next Token staging corpus

This is a local, draft corpus for Ben's review before the series is promoted
into the main episode documentation workflow.

## Scope

The channel currently has five long-form episodes: Episodes 00 through 04.
The request mentioned four videos and five episodes; this staging set includes
all five numbered episodes, including the pilot, Episode 00.

Each episode has:

- a public YouTube source;
- the YouTube automatic English caption track preserved as raw VTT;
- a cleaned, timestamped transcript derived from that VTT;
- public metadata JSON containing the title, description, duration, dates, and
  chapter data where YouTube exposes it;
- candidate section and theme notes in
  [`review-sections-and-themes.md`](./review-sections-and-themes.md).
- the five-lens capture rules in
  [`theme-capture-rules.md`](./theme-capture-rules.md).

## Review status

The transcripts are source-grounded but not human proofread. The sections and
themes are candidate analysis, not canonical episode copy. Proper names,
technical terms, and captions such as `[ __ ]` may need correction against the
video.

Start with [`review-sections-and-themes.md`](./review-sections-and-themes.md),
then use [`episode-catalog.md`](./episode-catalog.md) to open the relevant
transcript and raw source.

The existing detailed analysis of Episode 02 is linked from the review file:
[`analysis/pi-agent-configuration/02-next-token-pi-herdr-plannotator-workflow.md`](../analysis/pi-agent-configuration/02-next-token-pi-herdr-plannotator-workflow.md).

# Boosting AI Output Quality

Status: curated from imported YouTube captions and pipeline files.

Source episode: [`2025-07-01-ai-content-pipeline-2`](../../../2025-07-01-ai-content-pipeline-2)

## Purpose, audience, and message

Purpose: Improve the content pipeline output after the first end to end implementation.

Audience: Builders whose generated content is factually usable but weak in tone or structure.

Message: Output quality depends first on complete source data and task structure. Extract facts into a stable form, then polish them for the target channel.

## Tactical practices

- Whiteboard required data and links before changing prompts. See 02:53 to 07:12.
- Treat missing upstream data as a pipeline bug. See 02:53 to 05:20.
- Extract factual content before asking for tone and prose. See 11:08 to 15:47 and 33:20 to 41:18.
- Give the polishing step the target audience and channel context. See 41:18 to 49:44.
- Review output against the source transcript rather than style alone. See 54:02 to 01:02:11.

## Failure modes and limits

- One prompt that extracts and writes can omit facts while chasing tone.
- A polished draft can confidently preserve bad metadata.
- Rigid templates produce repetitive prose.
- Claims about quality are demonstrated on this pipeline, not a controlled evaluation.
